# All 워크플로우

## 목적
3종목 순차 실행 후 종합 스코어보드 출력

## 실행 순서

### Step 1: QC 실행
`workflows/qc.md` 참조. 결과 저장.

### Step 2: Code 실행
`workflows/code.md` 참조. 결과 저장.

### Step 3: Ready 실행
`workflows/ready.md` 참조. 결과 저장.

### Step 4: 종합 스코어보드 출력

각 종목의 점수를 100점 만점으로 정규화:
- QC: (통과/전체) × 100
- Code: 테스트 통과율 기준 (빌드/린트 fail이면 0점)
- Ready: (점수/20) × 100
- Total: 3종목 평균

```
╔══════════════════════════════════════╗
║     seeso-score: [프로젝트명]        ║
╠══════════╦═══════╦═══════╦══════════╣
║   QC     ║ Code  ║ Ready ║  Total   ║
║  [%]     ║  [%]  ║  [%]  ║   [%]    ║
╠══════════╩═══════╩═══════╩══════════╣
║ QC:    [n]/[m] 시나리오 확인         ║
║ Code:  빌드[?] 린트[?] 테스트 [%]   ║
║ Ready: [n]/20 (Critical: [n]건)     ║
╚══════════════════════════════════════╝
```
