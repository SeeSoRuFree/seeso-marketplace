# QC 워크플로우

## 목적
체크리스트 기반으로 "기능이 실제로 되는가?" 검증

## 실행 순서

### Step 1: 체크리스트 탐색
프로젝트에서 QC 체크리스트 파일을 찾는다:
- `QC_CHECKLIST.csv`
- `docs/QC_CHECKLIST.csv` 또는 `docs/QC_CHECKLIST.md`
- `*.qc.csv`

없으면 사용자에게 체크리스트 파일 경로를 물어본다.

### Step 2: 체크리스트 파싱
CSV/MD에서 항목 추출:
- 항목ID, 체크항목, 확인방법, 카테고리

### Step 3: 코드 매핑 확인
각 항목에 대해:
1. **확인방법**에서 라우트 추출 (예: `/signup`, `/seeker/cbt/*`)
2. 해당 라우트가 프론트엔드에 존재하는지 Glob으로 확인
3. 관련 API 엔드포인트가 백엔드에 존재하는지 Grep으로 확인
4. 존재하면 "자동 확인", 없으면 "미구현"

### Step 4: 결과 출력
```
QC: [통과]/[전체] ([%])
├── 자동 확인 (라우트+API 존재): N건
├── 수동 확인 필요: N건
└── 미구현: N건

미구현 항목:
- [항목ID] [체크항목]
- ...
```
