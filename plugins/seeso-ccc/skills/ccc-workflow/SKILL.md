# CCC 워크플로우

> 세션은 휘발되지만 슬랙은 남는다. 슬랙이 세션 간 브릿지.

## 핵심: 쓰레드 = 작업 단위

하나의 슬랙 쓰레드가 하나의 작업의 전체 생명주기를 담는다.
누구든 쓰레드에 컨텍스트를 얹을 수 있고, 다음 세션에서 그 쓰레드를 읽고 이어간다.

## 메시지 3종

**[기록]** — 컨텍스트 저장. 응답 불필요.
**[액션]** — @멘션 포함. 사람 응답 필요.
**[핸드오프]** — 세션/사람 간 인계. 완료/다음/참고 포함.

## 규칙

- 텍스트만 (이미지 금지 — MCP가 못 읽음)
- 본문 짧게, 상세는 쓰레드 reply로
- 기존 쓰레드 있으면 거기에 이어쓰기
