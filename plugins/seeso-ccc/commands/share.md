# CCC 채널에 작업 공유

$ARGUMENTS 에서 공유할 내용과 대상 채널을 파악해. 없으면 물어봐.

## 판단 기준

**새 쓰레드로 올릴 것인가?**
- 새로운 작업/주제 시작 → 새 쓰레드
- 기존 작업의 진행/업데이트 → 기존 쓰레드에 reply

**[기록] vs [액션]?**
- 누군가의 응답/판단이 필요하면 → `[액션] @담당자`
- 그냥 기록이면 → `[기록]`

## 메시지 포맷

### 새 쓰레드 (채널 본문)
짧게 3-5줄. 무엇 & 왜만.
```
{제목 한 줄}

목표: {1-2문장}
범위: {포함/미포함}
```
상세 내용은 바로 쓰레드 reply로 이어서.

### [기록] (쓰레드 reply)
```
[기록] {한 줄 제목}

{무엇을 왜 했는지}
- 변경: {파일/요약}
- 결과: {성공/실패/진행중}
```

### [액션] (쓰레드 reply)
```
[액션] @{담당자} {한 줄 제목}

{필요한 것}
1. {구체적 요청/질문}
2. {구체적 요청/질문}
```

## 실행
1. 현재 세션에서 한 작업을 정리
2. 위 포맷에 맞춰 메시지 작성
3. Slack MCP (conversations_add_message)로 포스팅
4. 새 쓰레드면 채널에, 기존 작업이면 해당 쓰레드에 reply

## 규칙
- 텍스트만. 이미지/스크린샷 절대 금지.
- 코드는 핵심 변경 부분만 발췌 (전체 파일 금지)
- 한 메시지 500자 이내 권장. 길면 쓰레드 reply로 분리.
