# 세션 핸드오프

세션이 끝날 때(또는 사용자가 요청할 때) 진행 중이던 작업의 현재 상태를 CCC 채널에 남긴다.
이 메시지가 다음 세션(내가 하든 다른 사람이 하든)의 시작점이 된다.

## 실행 순서

1. **현재 세션에서 한 작업 정리**
   - git log, git diff 로 변경 내역 확인
   - 커밋/PR 있으면 링크 포함
   - 해결한 것 / 남은 것 구분

2. **대상 채널 & 쓰레드 확인**
   - $ARGUMENTS 에서 채널/쓰레드 파악. 없으면 물어봐.
   - 기존 작업 쓰레드가 있으면 거기에 reply
   - 새 작업이었으면 새 쓰레드 생성 후 핸드오프

3. **핸드오프 메시지 작성**

```
[핸드오프] {한 줄 요약}

완료: {어디까지 했는지}
다음: {뭘 해야 하는지}
참고: {파일, PR 링크, 주의사항}
```

4. **Slack MCP (conversations_add_message)로 포스팅**

## 핸드오프 메시지 예시

```
[핸드오프] 채용 트렌드 위젯 API 연동 80% 완료

완료: mock → real API 전환, 에러 핸들링 추가
다음: 로딩 스켈레톤 UI, 빈 데이터 케이스 처리
참고: PR #145, agent-poc/services/trend_service.py 수정
```

## 규칙
- 텍스트만. 이미지/스크린샷 절대 금지.
- "다음" 항목은 구체적으로 — "마저 하기" 같은 애매한 표현 금지.
- 500자 이내 권장. 길면 쓰레드 reply로 분리.
- 받는 사람이 있으면 `[핸드오프] @{담당자}` 형식으로.
