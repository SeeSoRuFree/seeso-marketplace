# CCC 채널 컨텍스트 읽기

$ARGUMENTS 가 비어있으면 사용자에게 어떤 CCC 채널을 읽을지 물어봐. 채널명(예: #ccc-소문)이나 채널 ID를 받아.

## 실행 순서

1. **Slack MCP로 채널 최근 메시지 읽기** (conversations_history, limit: 1d)
2. **쓰레드 루트만 스캔** — 각 루트 메시지의 제목과 태그 확인
3. **주목할 쓰레드 식별**:
   - 나를 @mention한 쓰레드
   - [액션] 또는 [핸드오프] 태그가 있는 쓰레드
   - status가 open/blocked인 쓰레드
4. **주목할 쓰레드만 상세히 읽기** (conversations_replies)
5. **요약 보고**:

```
## CCC 채널 현황: #{채널명}

### 진행 중인 작업
- {쓰레드1 제목} — {현재 상태} — {담당자}
- {쓰레드2 제목} — {현재 상태} — {담당자}

### 내가 봐야 할 것
- {나를 멘션한 쓰레드 / 액션 요청}

### 이어갈 작업 제안
- {가장 우선순위 높은 것}
```

## 주의
- 쓰레드 전체를 다 읽지 말 것 — 루트 + 마지막 3개 메시지만 먼저 확인
- 관련 없는 쓰레드는 건너뛰기
- 이미지 메시지는 무시 (MCP가 못 읽음)
